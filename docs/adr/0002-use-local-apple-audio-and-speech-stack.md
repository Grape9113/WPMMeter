# Use the local Apple audio and speech stack

WPM Meter captures capturable system audio with a private, unmuted, mono Core Audio process tap and measures it locally with SpeechAnalyzer, using SpeechTranscriber for English and DictationTranscriber for Danish. The tap excludes WPM Meter itself and is consumed through a private aggregate audio device, which requests only System Audio Recording permission and never screen access. The app never falls back to SFSpeechRecognizer or a remote service because local-only processing, a single narrow capture permission, and bounded ephemeral state matter more than compatibility with older systems.
