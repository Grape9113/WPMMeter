# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for issue operations.

Infer the repository from its Git remote. Creating, reading, commenting on,
labelling, and closing tickets should operate on GitHub Issues.

Pull requests are not part of the triage queue.

When a skill says "publish to the issue tracker," create a GitHub issue.
When it says "fetch the relevant ticket," read the corresponding GitHub issue.
